cues - if the agent is slow on screen, keep talking and let the picture catch up.

Each wants different facts, on different deadlines, and nobody tells you which you missed."* |

## The 3 things the judge must remember

1. **Nothing is hard-coded** - the agent found the portals live, in that run.
2. **It tells you what you have not covered** - the amber box.
3. **A report is not a takedown** - it keeps watching.

## Before you record

- Use **https://reclaim-your-net.vercel.app**, not localhost.
- Turn **Practice mode ON** so the agent can fill the form (the real ones need a
  login). Turn it OFF for the 0:16 shot if you want the real portals.
- Record the whole thing in one take. Do not narrate over the agent's waiting
  time - pause the narration and let the browser move.
- Have a 15-second fallback clip of the live agent browser, in case the run is
  slow. Cut to it at 0:30.
